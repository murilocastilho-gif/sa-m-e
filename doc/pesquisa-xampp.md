# Pesquisa sobre XAMPP

## O que é o XAMPP?

O XAMPP é um pacote de software gratuito e de código aberto utilizado para criar ambientes de desenvolvimento web local. Seu nome é formado pelas iniciais de seus principais componentes:

* X = Cross-platform (multiplataforma)
* A = Apache
* M = MySQL/MariaDB
* P = PHP
* P = Perl

O objetivo do XAMPP é permitir que desenvolvedores criem, testem e executem aplicações web em seus computadores sem a necessidade de um servidor online.

## Principais Componentes

### Apache

O Apache é um servidor web responsável por processar as requisições dos usuários e exibir páginas web desenvolvidas em HTML, CSS, JavaScript e PHP.

### MySQL/MariaDB

O MySQL e o MariaDB são sistemas gerenciadores de banco de dados utilizados para armazenar informações da aplicação, como usuários, sensores e registros do sistema.

### PHP

O PHP é uma linguagem de programação voltada para o desenvolvimento web. É responsável pela lógica do sistema, processamento de formulários e comunicação com o banco de dados.

### phpMyAdmin

O phpMyAdmin é uma ferramenta gráfica que permite criar, editar e administrar bancos de dados através do navegador, sem a necessidade de comandos SQL complexos.

## Instalação e Configuração Básica

1. Acessar o site oficial do XAMPP.
2. Baixar a versão compatível com o sistema operacional.
3. Executar o instalador.
4. Selecionar os componentes desejados.
5. Concluir a instalação.
6. Abrir o painel de controle do XAMPP.
7. Iniciar os serviços Apache e MySQL.
8. Criar os projetos na pasta htdocs.
9. Acessar o sistema pelo navegador utilizando localhost.

## Importância para o Desenvolvimento Local

O XAMPP permite que aplicações PHP sejam desenvolvidas e testadas localmente, sem depender de servidores externos. Isso facilita correções, testes, manutenção e reduz custos durante o desenvolvimento.

## Aplicação no Projeto Ferrorama

O XAMPP será utilizado para executar o sistema Ferrorama localmente, permitindo o desenvolvimento das funcionalidades de cadastro, login e gerenciamento de sensores utilizando PHP e banco de dados MySQL/MariaDB.
